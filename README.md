# TUR-LASER — сайт лазерной очистки VIN-номеров

Статический сайт: `index.html` + `style.css` + `script.js`, без сборки и зависимостей.
Открывается двойным кликом по `index.html`, публикуется на GitHub Pages как есть.
Телефонная версия первична, ПК подстраивается.

## Что где

```
index.html          главная (блоки пронумерованы комментариями сверху вниз)
style.css           цвета и шрифты заданы переменными в :root
script.js           интерактив с лазером, слайдер «до/после», форма, нижняя панель
video/              process.mp4 (без звука, обрезан) + process-poster.jpg — второй блок
img/                before-N.jpg / after-N.jpg — галерея «до/после»
fonts/              Unbounded (заголовки) и Manrope (текст), лицензия OFL, лежат локально
policy/, consent/   политика конфиденциальности и согласие на обработку ПД
tools/placeholders.py   генератор заглушек «до/после», пока нет настоящих фото
```

## Что заменить перед запуском

Поиск по файлам покажет каждое место:

| Что | Сейчас | Где искать |
|---|---|---|
| Телефон | `+7 (900) 000-00-00` и `79000000000` | `grep -rn "9000000000" index.html policy consent` |
| WhatsApp / Telegram | `wa.me/79000000000`, `t.me/+79000000000` | там же |
| Город | «Москва и область» | `grep -n "Москв" index.html` |
| Адрес мастерской | «адрес уточним при записи» | блок «Контакты» |
| Часы работы | 9:00–21:00 без выходных | блоки «Цена», «Вопросы», «Контакты», форма |
| Реквизиты | ИП Фамилия И. О., ИНН, ОГРНИП | подвал `index.html`, `policy/`, `consent/` |
| Ссылка на отзывы | `href="#"` у кнопки «Все отзывы на Авито» | блок «Отзывы» |
| Отзывы | три карточки-заготовки с пометкой «Пример» | блок «Отзывы» |
| Фото «до/после» | заглушки `img/before-N.jpg`, `img/after-N.jpg` | положить настоящие под теми же именами, подписи в `.pair__cap` |
| Видео | `video/process.mp4` | см. ниже |

Решения, которые надо принять владельцу (на сайте сейчас написан осторожный вариант):

- что происходит с оплатой, если номер не проявился (сейчас: «вы ничего не теряете» без обещания вернуть деньги);
- выезд по области: включён или за доплату (сейчас: «договариваемся при заявке»);
- что входит в 4 800 ₽ (сейчас: выезд по городу, лазер + электрохимия, фото результата).

## Видео второго блока

Видео играет само, по кругу, без звука (`muted autoplay loop playsinline`) — иначе телефоны
его не запустят. Нарезка и удаление звука — через ffmpeg (бинарник есть в пакете
`imageio-ffmpeg`):

```
FF=$(~/.pyenv/versions/3.11.9/bin/python3 -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())")
$FF -y -ss 00:00:05 -t 20 -i исходник.mp4 -an -vf "scale=-2:960" -c:v libx264 -preset slow -crf 26 -movflags +faststart video/process.mp4
$FF -y -ss 00:00:06 -i исходник.mp4 -frames:v 1 -vf "scale=-2:960" video/process-poster.jpg
```

Держать ролик в 15–25 секунд и до 5–6 МБ: на телефоне он грузится первым после заголовка.

## Интерактив на первом экране

Canvas рисует ржавую пластину с номером. Мышка (на ПК — без нажатия) и палец (на телефоне)
стирают ржавчину, луч и искры идут за курсором. Когда очищено 85 % полосы с номером,
остаток дочищается сам и всплывает карточка с призывом. На телефоне луч сначала проходит
по номеру сам (демонстрация), пока человек не вмешался. При `prefers-reduced-motion`
анимация выключена. Номер на пластине показательный: `XW8 TURLASER 260001`.

## Куда уходят заявки

Сервера у сайта нет (GitHub Pages — только статика), поэтому форма сейчас:

1. проверяет поля и маску телефона;
2. показывает «Заявка принята» и кнопку «Отправить в WhatsApp» — текст заявки уже подставлен.

Чтобы заявки приходили сами, подключить один из вариантов (в `script.js` помечено место):

- **Formspree / Web3Forms** — бесплатный сбор форм на почту, 10 минут настройки;
- **Telegram-бот** через бессерверную функцию (Cloudflare Worker / Yandex Cloud Function),
  чтобы токен бота не лежал в коде сайта.

Правило из практики: заявка должна уходить в два канала (почта + мессенджер).

## Аналитика — в день запуска

В `<head>` есть место под Яндекс.Метрику; после вставки счётчика задать `window.YM_ID`.
Цели уже расставлены по кнопкам атрибутом `data-goal` и вызываются `track()`:

`call_click`, `wa_click`, `tg_click`, `cta_header`, `cta_hero`, `cta_vinlab`, `cta_price`,
`cta_mbar`, `form_submit`, `form_sent`, `vin_cleaned`, `vin_reset`, `reviews_click`.

Имена целей в кабинете Метрики должны совпадать буква в букву.

## Публикация на GitHub Pages

```
git init && git add index.html style.css script.js README.md .nojekyll fonts img video policy consent tools
git commit -m "TUR-LASER: прототип сайта"
gh repo create <аккаунт>/tur-laser --public --source=. --push
gh api -X POST repos/<аккаунт>/tur-laser/pages -f build_type=legacy -f 'source[branch]=main' -f 'source[path]=/'
```

Сайт появится по адресу `https://<аккаунт>.github.io/tur-laser/` через пару минут.
Все пути в разметке относительные, поэтому подпапка не ломает ссылки, шрифты и картинки.
`.nojekyll` обязателен, иначе Pages прогоняет папку через Jekyll.

После правок CSS/JS поднимать версию `?v=` в `index.html`, `policy/` и `consent/`,
иначе браузеры покажут старые стили.
