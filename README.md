# TUR-LASER — сайт лазерной очистки VIN-номеров

Статический сайт: `index.html` + `style.css` + `script.js`, без сборки и зависимостей.
Открывается двойным кликом по `index.html`, публикуется на GitHub Pages как есть.
Телефонная версия первична, ПК подстраивается.

## Что где

```
index.html          главная: шапка, первый экран, процесс, «до/после», цена и контакты, «не только VIN», подвал
style.css           цвета, шрифты и отступы заданы переменными в :root; телефон первичен, ПК с 900px
script.js           интерактив с лазером, лента «до/после», появление при прокрутке, нижняя панель
video/              process.mp4 (18 с, без звука) + process-poster.jpg — блок «Процесс»; lestnica.mp4 (14 с, без звука, кадр 3:4) + lestnica-poster.jpg — кейс «лестница»
img/                logo.png — логотип шапки (tools/logo_shapka.py); vinlab-base.jpg и vinlab-rust.jpg — слои интерактива; ba/ba-N-before|after.jpg — лента; more/lestnica-do|posle.jpg — кейс «лестница» в блоке «Не только VIN» (720×960, 3:4)
img/tg/             исходные фото с выездов (из них нарезаны ba/ и Авито)

policy/             политика конфиденциальности
tools/              генераторы логотипов и картинок для Авито; на сайт влияет только logo_shapka.py (img/logo.png)
```

## Видео второго блока

Видео играет само, по кругу, без звука (`muted autoplay loop playsinline`) — иначе телефоны
его не запустят. Нарезка и удаление звука — через ffmpeg (бинарник есть в пакете
`imageio-ffmpeg`):

```
FF=$(~/.pyenv/versions/3.11.9/bin/python3 -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())")
$FF -y -ss 00:00:05 -t 20 -i исходник.mp4 -an -vf "scale=-2:960" -c:v libx264 -preset slow -crf 26 -movflags +faststart video/process.mp4
$FF -y -ss 00:00:06 -i исходник.mp4 -frames:v 1 -vf "scale=-2:960" video/process-poster.jpg
```

Держать ролик в 15–25 секунд и до 5–6 МБ: на телефоне он грузится первым после заголовка.

## Интерактив на первом экране

Canvas кладёт фото ржавчины (`img/vinlab-rust.jpg`) поверх фото чистой таблички
(`img/vinlab-base.jpg`); пути заданы в `data-base` и `data-rust` у `#vinlab`. Если фото
не пришли за 4 секунды, рисуется запасная пластина. На ПК мышка (без нажатия)
стирает ржавчину, луч и искры идут за курсором. Когда очищено 85 % полосы с номером,
остаток дочищается сам, а под рамкой появляются «Номер читается» и ссылка «Оценить свой». На телефоне интерактива нет (решение
владельца 16.10.2026): луч сам проходит змейкой по полосе номера и дочищает его до конца, касания не учитываются. При `prefers-reduced-motion`
анимация выключена. Номер `XW8 TURLASER 260001` — только на запасной пластине.

## Как с нами связываются

Формы на сайте нет (решение владельца, октябрь 2026): человек звонит или пишет
в Telegram / MAX. Номер и ссылки стоят в шапке, на первом экране, в блоке
«Цена и контакты», в подвале и в нижней панели телефона. Понадобится форма —
её разметка, стили и скрипт (маска телефона, сборка текста заявки) есть в истории
git до коммита «контакты вместо формы», а страница `consent/` — там же.

## Аналитика — в день запуска

В `<head>` есть место под Яндекс.Метрику; после вставки счётчика задать `window.YM_ID`.
Цели уже расставлены по кнопкам атрибутом `data-goal` и вызываются `track()`:

`call_click`, `wa_click`, `tg_click`, `max_click`, `cta_vinlab`, `vin_cleaned`, `vin_reset`.

Имена целей в кабинете Метрики должны совпадать буква в букву.

## Шрифты

Оба с открытой лицензией OFL, файлы woff2 из fontsource (jsDelivr) лежат в `fonts/`.
Сторонних шрифтовых CDN на сайте нет.

- Montserrat (переменный, кириллица + латиница) — заголовки, логотип, цифры и телефон;
  начертание 800 в заголовках, 700 в подписях. Сменил Days One / Tektur / Orbitron
  по замечанию владельца «шрифт нужен формальнее»;
- Sofia Sans Semi Condensed (переменный, прямой и курсив) — текст.

## Публикация на GitHub Pages

```
git init && git add index.html style.css script.js README.md .nojekyll fonts img video policy tools
git commit -m "TUR-LASER: прототип сайта"
gh repo create <аккаунт>/tur-laser --public --source=. --push
gh api -X POST repos/<аккаунт>/tur-laser/pages -f build_type=legacy -f 'source[branch]=main' -f 'source[path]=/'
```

Сайт появится по адресу `https://<аккаунт>.github.io/tur-laser/` через пару минут.
Все пути в разметке относительные, поэтому подпапка не ломает ссылки, шрифты и картинки.
`.nojekyll` обязателен, иначе Pages прогоняет папку через Jekyll.

После правок CSS/JS поднимать версию `?v=` в `index.html` и `policy/`,
иначе браузеры покажут старые стили.
